# Microsoft Store listing

## The Readme - Markdown Editor

**Short description**

A native Windows workspace for Markdown, plain text, and source files. Edit and preview side by side, then find anything with an outline or search.

**Description**

Open a README and get straight to the document. The Readme is a lightweight, native Windows Markdown editor with live preview, document search, and a read-only workspace for source files.

Write Markdown and plain text, switch between Read and Edit, or use Split to see your Markdown take shape as you type. Format selections with bold, italic, headings, and inline code. Find your place in long documents with an outline that follows the headings, and use Save As to keep a separate copy.

Inspect Python, C, C++, Java, HDL, JSON, CSV, logs, and more. The Readme recognizes 134 extensions and 17 project filenames. Source files open in a read-only view with search, copy, line wrapping, and Go to line.

Choose from seven palettes or follow Windows. Reading and editing adjust to the window, with zoom from 60% to 220%. Open the built-in Markdown and Python examples to try it before choosing a file.

Work offline on local files. The Readme is free and open source from Shard Apps. The publisher receives no document content or analytics.

**What’s new**

First public preview on Microsoft Store. Includes the split Markdown editor, read-only source viewing, seven themes, and sample documents.

**Product features**

1. Markdown and plain-text editing with live split preview.
2. Bold, italic, strikethrough, inline code, and heading styles.
3. Read-only viewing for source code, data, configuration, and logs.
4. Heading outline, document search, line wrapping, and Go to line.
5. Seven themes, system appearance, and 60–220% zoom.
6. Offline use with drag and drop, recent files, and built-in samples.

## Certification notes

Requires no sign-in or external service. Select Try a sample from Home, choose Split, edit the Markdown, and use Save As to save a local copy. Home also includes a read-only Python example. The app package contains the .NET runtime.

The `runFullTrust` capability launches the packaged native WPF desktop process under the current user. It needs access to user-selected local documents through the file picker, drag and drop, file associations, and its optional Windows execution alias. It uses no admin service or elevation.

The Store download bundles the runtime. The approximately 2.6 MB size refers to the separate framework-dependent GitHub installer.
