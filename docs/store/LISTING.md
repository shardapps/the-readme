# Microsoft Store listing

## The Readme - Markdown Editor

**Short description**

A native Windows workspace for Markdown, plain text, and source files. Edit and preview side by side, then find anything with an outline or search.

**Description**

Open a README and get straight to the document. The Readme is a lightweight, native Windows editor for Markdown, plain text, and source files, with live Markdown preview and document search.

Write Markdown and plain text, switch between Read and Edit, or use Split to see your Markdown take shape as you type. Format Markdown selections with bold, italic, underline, headings, and inline code. Find your place in long documents with an outline that follows the headings, and use Save As to keep a separate copy.

Edit and save Python, C, C++, Java, HDL, JSON, CSV, logs, and more. Open source files as plain text with search, line wrapping, Go to line, and optional auto-indent. The Readme recognizes 134 extensions and 17 project filenames.

Choose from seven palettes or follow Windows. Reading and editing adjust to the window, with zoom from 60% to 220%. Try the built-in Markdown, Python, and HDL examples, and adjust animation and indentation in Settings.

Work offline on local files. This public preview is free and open source from Shard Apps. The publisher receives no document content or analytics.

**What’s new**

Edit and save HDL, Python, C++, Java, JSON, and other source files. Try the built-in HDL example, use underline in Markdown, and customize auto-indent and transition animations in Settings.

**Product features**

1. Markdown and plain-text editing with live split preview.
2. Bold, italic, underline, strikethrough, inline code, and heading styles in Markdown.
3. Plain-source editing for code, HDL, data, configuration, and logs.
4. Heading outline, document search, line wrapping, and Go to line.
5. Seven themes, system appearance, and 60–220% zoom.
6. Offline use with drag and drop, recent files, and built-in samples.

## Certification notes

Requires no sign-in or external service. Select Try a sample from Home, choose Split, edit the Markdown, and use Save As to save a local copy. Open an HDL example from Home to try source editing and save a .hdl copy. The app package contains the .NET runtime.

The `runFullTrust` capability launches the packaged native WPF desktop process under the current user. It needs access to user-selected local documents through the file picker, drag and drop, file associations, and its optional Windows execution alias. It uses no admin service or elevation.

The Store download bundles the runtime. The approximately 2.6 MB size refers to the separate framework-dependent GitHub installer.
