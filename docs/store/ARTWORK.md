# Store artwork

The Store listing uses screenshots captured from the WPF app running its public samples. The app pixels are unchanged apart from scaling for the 1920 × 1080 layout. A built-in ImageGen backdrop frames the captures and a separate ImageGen illustration serves as the text-free Store hero.

## Screenshot backdrop prompt

> Create a polished 16:9 landscape Microsoft Store promotional BACKGROUND ONLY for a native Markdown reading app. Entire central region must remain very low contrast and empty so an actual app screenshot can be composited later. Soft ink-indigo at edges fading into a very subtle midnight violet center, fine lilac dotted grid sparsely visible near corners, quiet hints of cool blue and plum edge glows. Premium, restrained software product art; airy, calm and crisp. No text, no typography, no app windows, no logos, no borders, no mock interfaces, no illustrative objects, no watermark. Seamless corner-to-corner background.

## Store hero prompt

> 16:9 Microsoft Store hero artwork for The Readme, a native Windows Markdown editor. No text, no letters, no logos, no user interface, no device. Create a premium editorial product still life in the upper two thirds, centered: a sharply folded luminous lilac sheet and two slim translucent lavender paper layers, a beveled jewel-violet folded corner, with a few subtle geometrical lavender lines suggesting a manuscript. Small reflected mint rim light on a smooth midnight indigo and aubergine setting, refined soft background, continuous edge-to-edge. Bottom third settles into a medium-dark quiet indigo gradient for Store overlays. Apple-quality restrained geometry, soft shadows, readable silhouette, crisp glass-paper material. No watermark.
